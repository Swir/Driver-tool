## 🚀 About

**Driver Tool** is an experimental Windows desktop utility for inspecting installed driver information and recent driver-related Windows updates from a Tkinter interface.

The application uses PowerShell / Windows management data to collect driver details and displays the results in a scrollable GUI. It is designed as a lightweight diagnostic helper rather than a full driver-management suite.

It is useful for users searching for a **Windows driver viewer**, **Python driver checker**, **PowerShell driver GUI**, **installed driver list tool** or a small Windows hardware-diagnostics utility.

## 📦 Installation

```bash
git clone https://github.com/Swir/Driver-tool.git
cd Driver-tool
python main.py
```

---

## ⚠️ Current Limitation

The **Update Drivers** button in the current version is a simulation/prototype feature and does **not** install real driver updates. Use Windows Update or your hardware vendor's official tools when performing actual driver updates.

## 🇵🇱 Polski

Driver Tool to eksperymentalna aplikacja dla Windows, która korzysta z PowerShella do wyświetlania informacji o zainstalowanych sterownikach i ostatnich aktualizacjach związanych ze sterownikami.

### ✨ Funkcje
- lista zainstalowanych sterowników i ich wersji
- pobieranie danych przez PowerShell / WMI
- sprawdzanie ostatnich hotfixów związanych ze sterownikami
- graficzny interfejs Tkinter
- przewijany panel wyników

### ⚠️ Ważne
Przycisk **Update Drivers** w obecnej wersji jedynie symuluje aktualizację i nie instaluje rzeczywistych sterowników. Projekt należy traktować jako prototyp/wersję rozwojową.

### 🚀 Uruchomienie

```bash
git clone https://github.com/Swir/Driver-tool.git
cd Driver-tool
python main.py
```

## 🇬🇧 English

Driver Tool is an experimental Windows application that uses PowerShell to display installed driver information and driver-related Windows hotfix data.

### ✨ Features
- list installed drivers and versions
- PowerShell / WMI based inspection
- display recent driver-related hotfix information
- Tkinter graphical interface
- scrollable results panel

### ⚠️ Important
The **Update Drivers** button currently performs a simulation only and does not install real driver updates. Treat the project as a prototype / work in progress.

### 🚀 Run

```bash
git clone https://github.com/Swir/Driver-tool.git
cd Driver-tool
python main.py
```
